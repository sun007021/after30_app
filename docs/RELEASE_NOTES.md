## 빌드 1 — 알람 스케줄링 핵심 (PR #18)

`fix/alarm-scheduling-core` · 커밋 3개 · 4개 파일, +94 / −36 · 빌드 통과

"알람이 울리지 않는다"로 보고된 증상의 근본 원인 4가지를 수정했습니다. 서버에는 약이 정상 등록돼 있어 화면상으로는 문제가 없어 보이지만, 실제 기기 알림 예약이 누락·충돌·소멸하던 경우입니다.

- 로그아웃할 때 기기에 저장된 알람 데이터를 전부 지우지 않도록 변경했습니다. 이제 로그아웃은 예약된 알림만 취소합니다.
- 이메일로 다시 로그인하면 저장된 알람이 자동으로 재예약됩니다. (기존에는 카카오 로그인 경로에만 있던 처리입니다.)
- 알림 식별자를 기기에 저장하도록 바꿔, 앱을 껐다 켠 뒤 새 약을 등록해도 기존 약의 알람을 덮어쓰지 않습니다.
- 주간 반복 알람을 요일 기반으로 예약하도록 바꿔, 매주 같은 요일에 반복해서 울립니다.
- 기기를 바꾸거나 앱을 다시 설치해도 서버에 등록된 약의 알람이 자동으로 예약됩니다.
